# 📻 RadioTotBot — Telegram Mini App

Мини-приложение для прослушивания интернет-радио прямо внутри Telegram.

**Демо:** https://organizm88.github.io/radio-mini-app/

## Возможности

- 30 000+ станций со всего мира через [Radio Browser API](https://www.radio-browser.info/)
- Показываются только рабочие станции (`hidebroken=true`)
- Фильтр по стране (120+ стран с флагами) и по жанру
- Поиск по названию с debounce
- Вкладки «Все», «❤️ Избранное», «🔥 Топ 100»
- Избранное, громкость и последняя станция сохраняются в `localStorage`
- Мини-плеер и полноэкранный плеер со свайпом вниз
- Управление с локскрина и наушников (Media Session API)
- Адаптация под тему Telegram (светлая/тёмная)

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка приложения |
| `styles.css` | Стили (CSS-переменные под тему Telegram) |
| `script.js` | Вся логика: API, поиск, фильтры, плеер |

## Локальный запуск

Сборка не нужна — это статические файлы:

```sh
python3 -m http.server 8000
```

Затем откройте http://localhost:8000

## Деплой

GitHub Pages публикует ветку `main` из корня — любой push в `main` сразу обновляет рабочую версию.
